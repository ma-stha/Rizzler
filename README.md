# Rizzler 💬

![Live Status](https://img.shields.io/badge/Status-Live-success)
![Platform](https://img.shields.io/badge/Platform-Web%20%7C%20Mobile--First-blue)

A lightning-fast, mobile-first anonymous chat platform designed for zero-friction conversations. Built with performance in mind, Rizzler skips the heavy frontend frameworks and databases to deliver instant, real-time messaging.

🌐 **Live Website:** [rizzler.online](https://rizzler.online)

---

## ✨ Features

* **Real-Time Messaging:** Powered by Socket.io for instant, two-way communication.
* **Anonymous by Design:** Jump straight into conversations without the friction of creating an account or logging in.
* **Mobile-First UI:** Optimized specifically for seamless mobile experiences, while remaining fully responsive on desktop.
* **Ultra-Lightweight:** Built with Vanilla JavaScript, HTML, and CSS to ensure zero-friction performance and lightning-fast load times.
* **Unique User Tracking:** Custom backend architecture handling real-time user state and connections efficiently.

## 🛠️ Tech Stack

**Frontend:**
* HTML5
* CSS3
* Vanilla JavaScript

**Backend:**
* [Node.js](https://nodejs.org/)
* [Express.js](https://expressjs.com/)
* [Socket.io](https://socket.io/) (Real-time web socket communication)

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

You will need Node.js installed on your machine.
* [Download Node.js](https://nodejs.org/en/download/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/ma-stha/rizzler.git](https://github.com/ma-stha/rizzler.git)
   cd rizzler

```

2. **Install dependencies:**
```bash
npm install

```


3. **Set up environment variables:**
Create a `.env` file in the root directory and configure your port (optional, defaults to 3000 if not specified).
```env
PORT=3000

```


4. **Start the server:**
```bash
npm start

```


*Alternatively, run `node server.js` (or your entry file name).*
5. **Open in browser:**
Navigate to `http://localhost:3000` to see the app running locally.

## 🚢 Deployment

Rizzler is designed to be easily deployed on platforms like **Render**, Heroku, or any Node-friendly hosting environment. Ensure your hosting provider is configured to support WebSockets and handles the `PORT` environment variable dynamically.
